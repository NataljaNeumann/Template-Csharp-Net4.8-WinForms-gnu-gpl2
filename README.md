# Template-Csharp-Net4.8-FinForms-gnu-gpl2
This is a template for a multilingual .Net Windows apps based on WinForms, GNU gpl-2.0-or-later, C#

 - The solution compiles with VS2026 community edition
 - Rename the "Template" folder to the name that you need
 - Search and replace the "Template" in all folders by the name of your own app.
 - Design your icon using the Gimp app.
 - Write your own Readme.html in Project folder, at the moment it contains a copy of the licence.
 - Write your own readme.md in the main folder. This is displayed at github.
 - Scalable vector graphics can be designed using Inkscape App.
 - Some useful tools that are used in project can be found in repositories of https://github.com/NataljaNeumann
 - In .github/workflows directory there is a workflow for automatic building your project and releasing a new version
 - There are more supported languages than supported by the operating system, so a culture selection dialog on the first start is useful.
