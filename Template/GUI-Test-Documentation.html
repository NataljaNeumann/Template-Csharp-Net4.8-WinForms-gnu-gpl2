Test Documentation

This document describes the expected behavior of the application, as is testable using the GUI.

OS Theme Test

  • Setup a dark theme in the operating system.
  • Start the application
  • Close the application
  • Setup a light theme in the operating system.
  • Start the application
  • Close the application

Expected results:

  • The application starts and closes
  • The application has light colors, when OS has light colors on startup
  • The application has dark colors, when OS has light colors on startup
  • Changing the color schema on-the-fly is not mandatory
