1) The solution compiles with VS2026 community edition.
2) Rename the "Template" folder to the name that you need
3) Search and replace the "Template" in all folders by the name of your own app.
4) Design your icon using the Gimp app.
5) Write your own Readme.html in Project folder, at the moment it contains a copy of the licence.
6) Write your own readme.md in the main folder. This is displayed at github.
7) Scalable vector graphics can be designed using Inkscape App.
8) Some useful tools that are used in project can be found in repositories of https://github.com/NataljaNeumann
9) In .github/workflows directory there is a workflow for automatic building your project and releasing a new version
10) There are more supported languages than supported by the operating system, so a culture selection dialog on the first start is useful.
